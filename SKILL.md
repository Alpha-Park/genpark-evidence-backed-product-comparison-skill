# GenPark Evidence-backed Product Comparison

Use this skill to compare candidate products without inventing missing facts.

## Procedure

1. Validate candidate records and comparison criteria.
2. Score only fields present in the input.
3. Preserve record indexes and evidence snippets for every match.
4. Mark missing information instead of guessing.

## Safety

Do not present generated rankings as endorsements. Ask the user to verify current availability, price, and suitability.
